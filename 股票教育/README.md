# 股票形态图书馆

一个**纯静态、可离线**的股票模型图解教育站。收录 **85 个**经典交易模型（要求 ≥50，实际超额完成），每个模型都用 **K 线 + 成交量**画出"长什么样"，点进去看形态要点、成交量特征、买卖规则、失效信号与常见误区。

> ⚠️ 仅作教学示例。K 线与成交量为模型示意（确定性生成，非真实行情），任何形态在历史中有效不代表未来成立，**不构成投资建议**。

---

## 一、怎么跑起来

本站无任何外部依赖、无需打包，双击 `index.html` 即可打开；但浏览器对 `file://` 下的 JS 有限制，推荐起一个本地服务：

```bash
cd 股票教育
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

## 二、目录结构（5 个 JS + 1 HTML + 1 CSS，全分离）

```
index.html        页面骨架 + 容器（目录视图 / 详情视图）
css/styles.css    设计令牌（深浅色）+ 卡片/详情/图表样式
js/rng.js         种子化伪随机数（让每个模型图刷新后不变）
js/candles.js     85 个形态生成器（核心，返回 candles+标注+叠加指标）
js/chart.js       SVG 渲染器：K线+成交量+标注+hover tooltip
js/data.js        85 个模型的文字资料（一句话/形态/量能/机理/买卖/失效/误区/出处）
js/app.js         目录渲染、搜索、分类筛选、hash 路由、深浅色切换
```

**数据驱动**：框架只写一次，85 个模型全靠 `data.js` 的数据 + `candles.js` 的生成器填充。加新模型只需两步（见下）。

## 三·5、详情页结构（11 节 + 回测，教"判断趋势"的元框架）

每个模型详情页都按同一套教学框架展开，目的是让用户学任何一个都在练"判断趋势"的能力，而不是死背形状：

1. **趋势判断三段论（先建框架）**：大势 → 个股趋势 → 形态位置，强调"同形不同位含义相反"。
2. **分步辨认清单**：把"形态长什么样"转成可逐条打勾的辨认步骤。
3. **成交量与量价配合**：该形态量能要点 + 通用的"量价三检查"。
4. **形成机理**：为什么会形成这个形态。
5. **买卖规则**：买入 / 止损两卡。
6. **目标位与止损测算**：形态高度量度法 + R 倍法（前瞻测算，非承诺收益）。
7. **多周期共振确认**：周/日/小级别三级共振。
8. **易混淆形态与区分**：与相近形态的区分要点 + 跳转对比。
9. **失效信号与失效后应对**：什么情况算失效 + 失效三步应对。
10. **常见误区**。
11. **实战自检表**：买前 8 条勾选，全绿再进场。

> 1/3/6/7/9/11 节为"通用框架"，按模型分类与方向自动填充；2/4/5/8/10 节来自该模型的 `data.js` 字段。新增模型**无需新增字段**，填好原有 `one/looks/vol/mech/buy/stop/fail/pitfall/related` 即可自动生成完整详情页。

## 三·6、模拟投资（看图决策练习）

顶部"🎮 模拟投资"进入。从 **340 题题库**随机出题（85 模型 × 4 变体：标准成功 / 失败陷阱 / 过早未确认 / 异种子），每题：

1. 显示一段走势到"此刻"（决策点），**模型名隐藏**——仅凭已显示 K 线判断；
2. 三选一：**买入 / 卖出 / 不交易**；
3. 揭晓完整走势 + 正解 + 计分 + 形态名 + 理由（陷阱题会点明"形态会失败"）；
4. 下一题 / 结束并查看战绩。

计分：判断正确 +10；方向相反或贸然操作 -5；错过机会(未操作) 0。
**无尽模式预案**：题库刷完自动洗牌续杯；"结束并查看战绩"随时可点；战绩页给题数/正确/胜率/积分/易错分类。

> ⚠️ 模拟投资行情由模型化生成、**非真实个股历史K线**；练习的是"看图决策"，不代表实盘胜率，不构成投资建议。真实历史K线案例请查各模型"来源"所列原书。

1. **红涨绿跌 + 空心涨/实心跌**：符合中国投资者直觉（同花顺/东方财富惯例）。同时"空心 vs 实心"是色盲友好的次级编码——即使红绿色弱也能区分涨跌（dataviz 校验脚本确认红绿对 CVD ΔE=13.3>12，达标）。
2. **深浅色独立调色**：不是简单反色，深色用调亮一档的涨色(#e66767)与暗背景搭配，文字对比度 ≥3:1。
3. **图表自绘 SVG、不用图表库**：教育站要在图上画"杯""柄""颈线""买点▲""止损▼"等标注，自绘 SVG 的标注自由度远高于 lightweight-charts 等交易库，且零依赖、可离线。
4. **确定性图形**：每个模型用 `id` 作 PRNG 种子，刷新/重开图形完全一致——教学图不能跳动。
5. **详情图带 hover tooltip**：移到任意一根 K 线显示开/收/高/低/量；目录缩略图为性能取舍不做交互。

## 五、如何新增一个模型（两步）

**第 1 步**：在 `js/candles.js` 的 `GEN` 对象里加一个生成器，返回 `{candles, ann, overlays?}`：

```js
GEN.my_pattern = function (seed) {
  const r = RNG.create(seed);
  const cs = build(seed, interp([
    { p: 92, v: V.normal, k: 3 },   // 起点，k=从上点到本点生成几根
    { p: 108, v: V.hot, k: 3 },    // 放量上攻
  ], r, 0.25));
  return {
    candles: cs, seed,
    ann: [ P(5, 100, "买点", "buy"), H(100, "阻力") ]  // 标注
  };
};
```

> 几何铁律：每根 candle 满足 `h ≥ max(o,c)` 且 `l ≤ min(o,c)`（用 `build()`/`mk()` 自动满足）。标注类型见 `chart.js`：`P`点、`H`水平线、`LINE`趋势线、`ZONE`区域、`LBL`文字、`OL`叠加线、`BAND`带状。

**第 2 步**：在 `js/data.js` 的 `MODELS` 数组加一条：

```js
{ id:"my_pattern", name:"我的形态", alias:"My Pattern", cat:"continuation", gen:"my_pattern", src:S.clas,
  one:"一句话总结",
  looks:["要点1","要点2"], vol:["量能1"], mech:"形成机理",
  buy:"买点", stop:"止损", fail:["失效1"], pitfall:["误区1"],
  related:["cup_handle"] }
```

`gen` 字段名必须与 `GEN.<name>` 一致；`cat` 取 `reversal/continuation/single/two/three/gap/system`。刷新即出现在目录。
