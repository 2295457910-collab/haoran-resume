# 🚀 PawMate 运行说明

## 📱 项目说明

这个项目**目前是一个Web应用**，不是完整的微信小程序。主要文件是：
- `app.html` - Web应用主页面
- `app.js` - Web应用逻辑代码

## 🌐 方法1：作为Web应用运行（推荐）

### 这是当前最简单、最完整的运行方式！

#### 选项A：直接打开（简单但功能受限）
1. 双击打开 `app.html` 文件
2. 会在默认浏览器中打开
3. **注意**：某些功能可能受限（如地图API）

#### 选项B：使用本地服务器（推荐）
**Python方式（Mac/Linux自带）：**
```bash
# 在项目目录下打开终端，运行：
python3 -m http.server 8000

# 然后在浏览器访问：
# http://localhost:8000/app.html
```

**Node.js方式：**
```bash
# 安装http-server（只需一次）
npm install -g http-server

# 在项目目录运行
http-server -p 8000

# 浏览器访问：
# http://localhost:8000/app.html
```

**VS Code方式：**
1. 安装"Live Server"扩展
2. 右键点击 `app.html`
3. 选择"Open with Live Server"

### 推荐浏览器
- ✅ Chrome / Edge（推荐）
- ✅ Safari
- ✅ Firefox

## 📱 方法2：作为微信小程序运行

### ⚠️ 当前状态
我已经创建了基础配置文件：
- ✅ `app.json` - 小程序配置
- ✅ `sitemap.json` - 索引配置

### ❌ 还缺少的内容
微信小程序需要特定的目录结构和文件，目前**缺少**：
```
pages/
├── index/
│   ├── index.wxml  (页面结构)
│   ├── index.js    (页面逻辑)
│   ├── index.wxss  (页面样式)
│   └── index.json  (页面配置)
├── discover/
├── messages/
├── shop/
└── profile/
```

### 如果要转换为微信小程序：

#### 步骤1：创建页面目录
```bash
mkdir -p pages/index
mkdir -p pages/discover
mkdir -p pages/messages
mkdir -p pages/shop
mkdir -p pages/profile
```

#### 步骤2：需要做的工作
1. **将HTML转换为WXML**
   - HTML标签 → 小程序组件
   - `<div>` → `<view>`
   - `<img>` → `<image>`
   - CSS类名保持不变

2. **将CSS转换为WXSS**
   - 基本语法相同
   - 移除不支持的CSS属性
   - 调整单位（可能需要用rpx）

3. **改写JavaScript**
   - Web API → 小程序API
   - `navigator.geolocation` → `wx.getLocation`
   - `fetch` → `wx.request`
   - `document.getElementById` → `this.selectComponent`

4. **地图集成**
   - 使用微信小程序的 `<map>` 组件
   - 替换Leaflet地图库

#### 步骤3：申请权限
在微信公众平台配置：
- 位置接口权限
- 地图服务权限
