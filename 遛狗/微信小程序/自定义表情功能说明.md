# 自定义表情功能说明

## 功能概述

PawMate聊天功能新增了**自定义表情**功能，用户可以上传自己的图片作为收藏表情，让聊天更加个性化和有趣。此功能完美融合了用户个性化需求与遛狗社交场景。

## 🎯 功能特性

### ✨ 核心功能
- **图片上传**: 支持从相册选择或拍照上传
- **一键收藏**: 上传的图片自动成为收藏表情
- **智能提示**: 自动检测图片尺寸并给出优化建议
- **本地存储**: 表情数据安全保存在本地
- **数量限制**: 最多支持50个收藏表情，防止存储溢出

### 🎨 用户体验
- **可视化入口**: 收藏表情区域的"+"按钮
- **多种上传方式**: 相册选择 / 拍照上传
- **实时预览**: 上传前确认预览
- **差异化删除**: 自定义表情删除时特殊提示
- **智能排序**: 新添加的表情显示在前面

## 📱 使用方法

### 添加自定义表情
1. **进入聊天页面** → 点击表情按钮 😊
2. **切换到收藏标签** → 点击 ⭐ 标签
3. **点击添加按钮** → 点击带虚线边框的 ➕ 按钮
4. **选择图片来源**:
   - 从相册选择：从手机相册中选择图片
   - 拍照：直接拍摄新照片
5. **确认添加** → 预览图片后点击"添加"

### 使用自定义表情
1. **发送表情**: 在收藏表情中点击自定义表情即可发送
2. **管理表情**: 长按表情可以删除（会有特殊确认提示）

### 删除自定义表情
1. **长按表情** → 在收藏表情区域长按要删除的表情
2. **确认删除** → 自定义表情会显示红色确认按钮和特殊提示
3. **注意**: 删除后无法恢复，请谨慎操作

## ⚙️ 技术规格

### 图片要求
- **推荐尺寸**: 500x500像素以内的正方形图片
- **文件格式**: 支持 JPG、PNG 等常见格式
- **压缩处理**: 自动压缩图片以优化性能
- **存储位置**: 小程序本地存储空间

### 存储限制
- **数量限制**: 最多50个收藏表情
- **自动清理**: 超出限制时删除最早添加的表情
- **存储方式**: 临时文件路径 + 本地存储索引

### 性能优化
- **懒加载**: 表情按需加载显示
- **图片压缩**: 自动压缩减少存储占用
- **错误处理**: 完善的异常处理机制

## ⚠️ 注意事项

### 图片选择建议
1. **尺寸建议**: 选择正方形或接近正方形的图片效果最佳
2. **清晰度**: 选择清晰、对比度高的图片
3. **内容适宜**: 确保图片内容健康、积极向上
4. **版权注意**: 避免使用有版权争议的图片

### 技术限制说明
1. **临时路径**: 小程序重启后可能需要重新加载图片
2. **存储限制**: 受小程序本地存储容量限制
3. **兼容性**: 不同设备的图片处理能力可能有差异
4. **网络依赖**: 图片上传和处理需要良好的网络环境

### 最佳实践
1. **定期整理**: 及时删除不需要的表情释放存储空间
2. **合理命名**: 虽然系统自动命名，但建议选择有代表性的图片
3. **备份重要**: 重要的自定义表情建议保存原图备份
4. **适量使用**: 避免过度添加造成选择困难
