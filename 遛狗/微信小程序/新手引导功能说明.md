# 新手引导功能 - 产品说明文档

## 📋 功能概述

新手引导功能是为了帮助首次使用PawMate遛狗社交小程序的用户快速了解和掌握核心功能。通过简洁的弹窗引导，让用户在几秒钟内了解如何完善个人资料、使用地图功能和发起约遛狗邀请。

## 🎯 设计理念

### 参考市面上APP的指导方式
- **微信**：简洁的功能介绍，一步一个重点
- **支付宝**：渐进式引导，不会一次性展示太多信息
- **美团**：通过emoji和简短文字说明核心操作

### 核心原则
- **简洁明了**：每个引导步骤控制在15字以内
- **适时出现**：只在用户首次使用时显示
- **可跳过**：用户可以随时跳过引导
- **渐进式**：按使用流程逐步引导

## 🚀 功能特性

### 1. 智能触发机制
- **首次检测**：通过本地存储判断是否为新用户
- **页面级控制**：每个页面独立管理引导状态
- **全局状态管理**：统一管理所有引导的完成状态

### 2. 三大核心引导

#### 个人资料引导
- **触发时机**：首次进入个人资料页面
- **引导内容**：提示用户完善个人信息和宠物信息
- **后续动作**：引导完成后自动打开编辑界面

#### 地图功能引导
- **触发时机**：首次进入地图页面
- **引导内容**：三步式引导
  1. 介绍如何查看附近狗友
  2. 说明如何点击头像进行互动
  3. 介绍"开始遛狗"功能的使用方法

#### 约遛狗引导
- **触发时机**：首次发起约遛狗时
- **引导内容**：三步式引导
  1. 功能介绍
  2. 选择时间地点
  3. 等待回复

### 3. 现代化UI设计
- **背景遮罩**：70%透明度黑色遮罩
- **卡片设计**：圆角白色卡片，带阴影效果
- **动画效果**：淡入淡出 + 缩放动画
- **步骤指示器**：圆点进度条，当前步骤高亮

## 🎨 视觉设计

### 设计风格
- **温馨友好**：使用emoji图标，降低学习门槛
- **品牌一致**：延续PawMate的蓝紫色渐变主题
- **层次清晰**：标题、描述、按钮层次分明

### 交互体验
- **防误触**：点击遮罩不会关闭引导
- **流畅动画**：所有状态切换都有平滑过渡
- **触觉反馈**：按钮点击有缩放效果

## 🔧 技术实现

### 组件化设计
```
components/guide-modal/
├── guide-modal.wxml    # 引导弹窗结构
├── guide-modal.js      # 引导逻辑控制
├── guide-modal.wxss    # 引导样式设计
└── guide-modal.json    # 组件配置
```

### 数据结构
```javascript
// 全局引导状态
globalData: {
  isFirstTime: true,
  guideStatus: {
    profile: false,    // 个人资料引导
    map: false,        // 地图功能引导
    meetup: false      // 约遛狗引导
  }
}
```

### 核心方法
- `checkFirstTime()` - 检查首次使用状态
- `shouldShowGuide(type)` - 判断是否需要显示指定引导
- `completeGuide(type)` - 标记指定引导已完成
- `markAsUsed()` - 标记用户已使用过应用

## 📱 用户使用流程

### 新用户首次使用
1. **启动应用** → 检测为新用户
2. **进入个人资料** → 显示欢迎引导
3. **完善资料** → 引导用户填写信息
4. **使用地图** → 显示地图功能引导（包含开始遛狗功能）
5. **发起约遛狗** → 显示约遛狗流程引导
6. **完成所有引导** → 标记为老用户

### 老用户再次使用
- 不会显示任何引导弹窗
- 直接进入正常使用流程
