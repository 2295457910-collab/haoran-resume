# 个人资料编辑功能产品说明

## 📋 产品概述

### 产品背景
在遛狗社交场景中，用户的个人资料不仅代表个人形象，更承载着建立信任、促进社交的重要功能。参考Boss直聘的"公司名+个人名"展示模式，我们设计了"宠物信息+主人昵称"的展示方案，既保护隐私又增强社交属性。

### 核心价值
- **身份标识**：通过宠物品种/名字快速建立用户身份认知
- **信任建立**：完善的资料展示增强用户间的信任感
- **社交促进**：个性化信息成为破冰话题，促进交流
- **隐私保护**：灵活的隐私设置满足不同用户需求

## 🎯 功能特性

### 1. 智能展示系统
#### 展示逻辑（参考Boss直聘）
```
Boss直聘: 腾讯 · 张三
PawMate: 金毛犬 · 李四
```

#### 展示优先级
1. **显示宠物品种** → "金毛犬 · 用户昵称"
2. **仅显示宠物名字** → "Max主人 · 用户昵称"
3. **隐私模式** → "用户昵称"

### 2. 头像管理系统
#### 多种上传方式
- **相册选择**：从手机相册选择照片
- **拍照上传**：直接拍摄新照片
- **默认头像**：系统预设的可爱头像库

#### 智能优化
- **自动压缩**：上传时自动压缩图片，节省存储空间
- **格式支持**：支持JPG、PNG等主流格式
- **尺寸适配**：自动适配不同尺寸的头像显示

### 3. 宠物信息管理
#### 信息字段
- **宠物品种**：如金毛犬、拉布拉多、边牧等
- **宠物名字**：如Max、Lucky、球球等
- **个人简介**：100字以内的自我介绍

#### 验证机制
- **字符限制**：品种/名字最多15字符，简介最多100字符
- **内容审核**：自动过滤不当内容
- **实时预览**：编辑时实时显示最终效果

### 4. 隐私保护设计
#### 细粒度控制
- **宠物品种显示**：独立开关控制
- **宠物名字显示**：独立开关控制
- **组合展示**：支持多种展示模式组合

#### 隐私策略
- **默认显示**：新用户默认显示宠物品种
- **用户自主**：完全由用户控制信息展示程度
- **动态调整**：随时可修改隐私设置

## 💻 技术实现架构

### 1. 数据结构设计
```javascript
userInfo: {
  avatar: String,        // 头像URL
  name: String,          // 用户昵称
  description: String,   // 个人简介
  petBreed: String,      // 宠物品种
  petName: String,       // 宠物名字
  showPetBreed: Boolean, // 是否显示宠物品种
  showPetName: Boolean   // 是否显示宠物名字
}
```

### 2. 核心算法
#### 展示名称生成
```javascript
generateDisplayName(userInfo) {
  let displayName = userInfo.name || '遛狗达人';
  
  if (userInfo.showPetBreed && userInfo.petBreed) {
    return `${userInfo.petBreed} · ${displayName}`;
  } else if (userInfo.showPetName && userInfo.petName) {
    return `${userInfo.petName}主人 · ${displayName}`;
  }
  
  return displayName;
}
```

#### 本地存储
- **主数据**：用户基本信息存储在本地
- **临时数据**：编辑过程中的临时数据
- **缓存机制**：头像等资源的缓存策略

#### 数据同步
- **实时保存**：关键信息实时保存到本地
- **版本管理**：支持数据版本控制
- **错误恢复**：异常情况下的数据恢复机制

## 📱 用户使用指南

### 1. 基础编辑流程
#### 步骤说明
1. **进入编辑**：点击个人资料页面的"编辑"按钮
2. **修改信息**：在弹窗中修改各项信息
3. **设置隐私**：选择信息的显示/隐藏
4. **预览效果**：查看最终显示效果
5. **保存变更**：点击"保存"按钮完成编辑

### 2. 头像更换指南
#### 操作步骤
1. **触发更换**：点击头像或"更换头像"按钮
2. **选择方式**：相册选择/拍照/默认头像
3. **图片处理**：系统自动压缩和优化
4. **确认保存**：预览满意后保存

### 3. 隐私设置建议
#### 推荐配置
- **新用户**：建议显示宠物品种，隐藏宠物名字
- **活跃用户**：根据社交需求灵活调整
- **隐私敏感**：只显示昵称，隐藏宠物信息
