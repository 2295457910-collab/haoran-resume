# PawMate 遛狗社交小程序 - 快速使用指南

## 🚀 快速开始

### 1. 打开微信开发者工具
1. 下载并安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开微信开发者工具
3. 使用微信扫码登录

### 2. 导入项目
1. 点击"导入项目"
2. 选择本文件夹：`C:\Users\haoran.wang\Desktop\cursor原型\新建文件夹\微信小程序`
3. 填写项目信息：
   - **项目名称**：PawMate遛狗社交
   - **AppID**：选择"测试号"（或填入您的小程序AppID）
   - **开发模式**：小程序

### 3. 编译运行
1. 点击工具栏的"编译"按钮
2. 在模拟器中查看效果
3. 可以选择不同的设备型号进行预览

## 📱 功能演示

### 地图页面（主页）
- **查看附近用户**：地图上显示附近遛狗的用户标记
- **点击用户标记**：查看用户详细信息
- **筛选功能**：点击右上角"筛选"按钮，可以按距离、活跃时间等筛选
- **定位功能**：点击左上角定位按钮回到当前位置

### 约遛狗功能（核心功能）
1. 在地图页面点击用户信息卡片的"📅 约遛狗"按钮
2. 选择日期：点击日期选择器
3. 选择时间：可以快速选择（早晨/下午/傍晚）或自定义时间
4. 选择地点：公园/小区周边/河边步道/其他（可自定义）
5. 添加备注：快捷短语或自定义输入
6. 预览信息：确认无误后点击"发送邀请"

### 消息中心
- **约遛狗标签**：查看发送和接收的约遛狗邀请
- **处理邀请**：对收到的邀请可以选择"同意"或"拒绝"
- **聊天记录**：查看与其他用户的聊天记录
