# PawMate 遛狗社交小程序

一个基于微信小程序的遛狗社交应用，帮助狗主人找到附近的遛狗伙伴。

## 功能特色

### 🗺️ 地图社交
- 实时显示附近遛狗用户
- 地图标记和用户信息卡片
- 智能筛选（距离、活跃时间）
- 真实地图定位和导航

### 📅 约遛狗系统
- **完整的约遛狗流程**
- 日期时间选择（支持快捷选择）
- 地点选择（公园、小区、河边等）
- 备注信息（快捷备注+自定义）
- 实时预览和状态管理

### 💬 消息中心
- 约遛狗邀请管理
- 同意/拒绝/取消功能
- 聊天记录管理
- 实时状态更新

### 🔍 发现页面
- 热门动态分享
- 遛狗经验交流
- 社区互动功能

## 开发环境设置

### 1. 微信开发者工具
1. 下载并安装微信开发者工具
2. 创建新项目，选择小程序类型
3. 导入本项目文件夹

### 2. 项目配置
```json
{
  "appid": "你的小程序AppID",
  "projectname": "PawMate遛狗社交"
}
```

### 3. 权限配置
在 `app.json` 中已配置：
- 地理位置权限
- 后台定位权限

## 核心页面说明

### 地图页面 (map)
- 使用微信小程序原生地图组件
- 实时获取用户位置
- 显示附近遛狗用户标记
- 支持筛选和用户信息查看

### 约遛狗页面 (meetup)
- **完整的约遛狗表单**
- 日期选择器（限制30天内）
- 快捷时间选择（早晨/下午/傍晚）
- 地点选择（4种预设+自定义）
- 备注系统（快捷短语+自定义输入）
- 实时预览和验证

### 消息中心 (messages)
- 约遛狗邀请管理
- 聊天记录查看
- 状态实时更新
- 支持同意/拒绝操作

## 使用方法

### 1. 在微信开发者工具中打开
1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择本项目文件夹
4. 填入测试AppID或使用测试号

### 2. 预览和调试
1. 点击"编译"按钮
2. 在模拟器中查看效果
3. 使用真机调试测试地图功能

### 3. 发布上线
1. 完善小程序信息
2. 提交审核
3. 发布上线

## 技术特点

- **原生小程序开发**：使用微信小程序原生框架
- **响应式设计**：适配不同屏幕尺寸
- **地图集成**：微信小程序地图组件
- **数据持久化**：本地存储+全局状态管理
- **用户体验**：流畅的动画和交互

## 注意事项

1. **地图功能**需要在真机上测试，模拟器可能无法完全展示
2. **位置权限**需要用户授权才能正常使用
3. **网络图片**需要在小程序后台配置域名白名单
4. **真实部署**时需要配置合法的服务器域名
