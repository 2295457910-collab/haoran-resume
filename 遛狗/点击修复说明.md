## 🚀 如何使用

### 方法1：直接点击地图标记
1. 打开地图页面
2. 找到彩色的用户标记（圆形图标）
3. 直接点击标记
4. 查看弹出的用户详情卡片

### 方法2：使用Popup查看详情
1. 点击地图标记
2. 会先弹出一个小的popup窗口
3. 点击popup中的"查看详情"按钮
4. 打开完整的用户详情卡片

### 方法3：使用测试按钮
1. 找到地图右上角的绿色按钮（试管图标🧪）
2. 点击该按钮
3. 自动显示第一个用户的详情
4. 用于测试功能是否正常
